Kumot

Back in the Philippines, seemingly every home had the same kind of blanket. This blanket:

img

I’ve had these back home while growing up. It was comfy. It was airy (Philippines is a humid tropical place). It didn’t tatter and lasted years.

I made a webtoy that draws this pattern with random procedurally generated flowers to go along with it. I called it Kumot, which literally means ‘blanket’.

[kú•mot] noun
blanket. some dictionary

This post I go over how I created it.

The algorithm

It starts with the base striped pattern. I’ve looked up examples online, and while proportions vary, there is a consistent pattern.

img

The colors are kind of a strong primary pastel color against white. I’ve put a hue selector for the most typical colors you’d find in real life.

img img img

The flowers were the most complex thing in this project and the aspect I spent the most time on.

img

Basically, it’s drawn in a polar coordinate fashion. If you laid out the angle and the distance as x- and y-coordinates in a Cartesian plane, it becomes obvious how this was built. It’s just a sinusoid mirrored in half to produce the basic lobes for the petals.

interactive (slider: polar-cartesian)

The contour is further shaped by an exponent. Remember that 0x = 0 and 1x = 1, and anything in between stays between 0 and 1, no matter the exponent, so we can freely randomise the exponent. The exponent essentially describes how full or thin the petals are, so we can go from daisy to hibiscus and everything in between.

interactive (slider: petal exponent) img left daisy img right hibiscus

Up until now, it still looks unnatural and perfectly geometric. Let’s make some noise. A simple coherent fractal noise (e.g. Perlin, simplex) gives that natural imperfection.

interactive (slider: noise proportion)

Some flowers have more than one layer of petals. This is easy, we just draw the same thing smaller with some angular offset. Draw order is important! Back to front.

interactive: layers

The rest of the details are simple lines and fills individually, but together give a lot of depth. The trick I used to fake 3D is to bias each point of the flower towards a certain direction proportional to its distance from the center.

interactive: draggable facing direction checkbox veins checkbox fill checkbox stamen

The leaves are drawn last, and behind the petals using a composite operation that only allows transparent pixels to be overwritten. Useful trick when you don’t want to deal with layers. Draw order is not that critical after all.

Actually, the draw order here must serves the animation more than the z-ordering. I need the petals to animate first! If we did the standard back-to-front draw ordering, it wouldn't look nice in the animation.

The flowers fade after a time. The fade effect uses a component-wise addition instead of standard opacity-based fade. It’s hard to explain, just see the example:

fade animation 1 fade animation 2 fade animation 3

Flowers are composited onto the base stripe pattern using the mutiply blend mode, which mimics how dyes work.

real world example img kumotgen img

Finally some fabric textures using repeated linear gradients and some noise.
