    Letters with no Baybayin equivalent

    Baybayin has no characters for C, F, J, Q, V, X, and Z. To use foreign words or names in Baybayin, spell the word the way it sounds in the Tagalog alphabet (abakada) instead.

    Baybayin cheatsheet

    Baybayin is generally written using one character per syllable. It’s an abugida, you see.

    ᜊᜓbuᜑhaᜌ᜕y

    Only three vowels

    Fourteen consonants

    The kudlit mark changes the vowel. When above it makes an ‘e/i’ sound. Below it makes an ‘o/u’ sound. A final mark kills the vowel.
